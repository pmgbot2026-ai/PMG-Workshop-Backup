สถาปัตยกรรมระบบ Dashboard สำหรับติดตามผลงาน PMG — ตั้งแต่ข้อมูลต้นทางถึงหน้าจอผู้ใช้

📋 Job Description — ระบบ PMG War Room

🎯 วัตถุประสงค์

Dashboard แบบ Real-time สำหรับผู้บริหารและทีม PMG ติดตามผลงานขาย รายได้ กำไร และ KPI รายเดือน/รายปี เปรียบเทียบเป้าหมาย แสดงผลด้วยกราฟแท่ง เส้น และ ตาราง บนมือถือเป็นหลัก

🏗️ สถาปัตยกรรม — 4 ชั้น

  • Data Source: Google Spreadsheets 3 ไฟล์ — ไฟล์หลัก (D1_DTA1) + ไฟล์ประวัติ + ไฟล์เสริม
  • Backend: Google Apps Script (Code.gs) — อ่านข้อมูลจาก Spreadsheets → แปลง → ส่งเป็น JSON
  • Frontend: HTML/JS (Index.html) — รับ JSON → วาด Chart.js กราฟ + ตาราง KPI
  • Delivery: GAS Web App — ให้บริการผ่าน URL เดียว เข้าดูได้ทุกอุปกรณ์

📊 แท็บข้อมูล 13 หน้า

  • Dashboard — ภาพรวม KPI สำคัญ (รถ/เป้า/รายได้/กำไร)
  • OKR/KPI — เป้าหมาย vs ผลจริงรายเดือน
  • ปิดได้/ส่งมอบ — จำนวนรถปิดได้ vs เป้าหมาย
  • การเงิน — รายได้ กำไร GM% รายเดือน
  • ประกันภัย — เบี้ยประกัน แบ่งตามบริษัท
  • ช่องทาง — ยอดขายแยกตามช่องทาง
  • SA — ผลงาน SA รายบุคคล
  • เชียร์เคลม — ข้อมูลเคลมรถเช่าซื้อ
  • YoY — เปรียบเทียบปี 67/68/69
  • DTA — ข้อมูล DTA รายเดือน
  • ข้อมูลย้อนหลัง — ข้อมูลสะสมหลายปี
  • ประเภทซ่อม — แยกประเภทงานซ่อม
  • ผลิตภัณฑ์เสริม — เบี้ยเสริม แยก SA/ผลิตภัณฑ์/รายเดือน

⚙️ เทคโนโลยีหลัก

  • Frontend: HTML5 + CSS3 + Vanilla JS (no framework) — มือถือ First
  • Charts: Chart.js 4.4.7 + chartjs-plugin-datalabels 2.2.0 (CDN)
  • Backend: Google Apps Script — SpreadsheetApp + HtmlService
  • Data: Google Sheets (3 spreadsheets, private access)
  • Deploy: clasp CLI → push to GAS → deploy as Web App

🔀 Flowchart — ขั้นตอนการทำงานของระบบ

Frontend (Index.html)

  • • Single-page HTML — ไม่มี framework
  • • Chart.js 4.4.7 + datalabels plugin
  • • 13 tabs, responsive, มือถือ First
  • • google.script.run → 13 async calls
  • • dlCfg() ตั้งค่า datalabels สีฟ้าสด
  • • mkC() สร้าง chart + auto-inject padding

Backend (Code.gs)

  • • doGet() → createHtmlOutputFromFile
  • • 13 data functions → JSON objects
  • • CacheService 5 min TTL
  • • Debug endpoints (?debug, ?api)
  • • SpreadsheetApp.openById() × 3
  • • ไม่มี HtmlTemplate (Caja issue)

Data Sources (3 Sheets)

  • • ไฟล์หลัก: OKR/การเงิน/ช่องทาง/SA
  • • ไฟล์ประวัติ: YoY/ข้อมูลย้อนหลัง
  • • ไฟล์เสริม: ประกันภัย/เคลม/ผลิตภัณฑ์
  • • Private access → ต้องผ่าน GAS เท่านั้น
  • • v13.42+ ใช้ google.script.run โหลดข้อมูล
  • • เคลือบแก้ว tab ถูกลบออกแล้ว
