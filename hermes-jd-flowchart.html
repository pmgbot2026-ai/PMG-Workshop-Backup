📋 หน้าที่ละเอียด

🔧 พัฒนา & แก้โค้ด

  • เขียน/แก้ไข HTML, CSS, JavaScript, Google Apps Script
  • ค้นหาบั๊ก แก้ไข และ deploy ได้ภายใน
  • จัดการ version รวมถึง deployment pipeline
  • สร้างกราฟ Chart.js + DataLabels plugin

🐛 ดีบั๊ก & แก้ปัญหา

  • วิเคราะห์หน้าจอ → หา root cause
  • ทดสอบด้วย curl, browser, vision_analyze
  • วนลูปแก้จนกว่าจะได้
  • บันทึก lessons learned ใน memory + skills

🚀 Deploy & จัดการระบบ

  • clasp push -f → clasp deploy → ส่ง URL ใหม่
  • จัดการ config, env, spreadsheet IDs
  • รักษา memory ข้าม session
  • ตั้ง Cron ส่งสรุปอัตโนมัติ

📨 สื่อสาร & ประสานงาน

  • ส่งไฟล์/ข้อความผ่าน Telegram group
  • รับ feedback จากมือถือ → แก้ไข → ส่งกลับ
  • สร้างเอกสาร HTML/flowchart/JD
  • สรุป KPI ขั้นเคลื่อน ส่งทุกวัน 8:00

⚡ ความสามารถพิเศษ

  • อ่านไฟล์ Projectได้ทั้ง local และ remote
  • ค้นหา code (grep/ripgrep) ได้เร็ว
  • รัน shell command ได้ (build, test, deploy)
  • เขียน/แก้ไขไฟล์ ได้ตรง
  • วิเคราะห์ภาพหน้าจอ (screenshot)
  • ดึงข้อมูลจาก API/web
  • ส่งข้อความ/ไฟล์ผ่าน Telegram
  • จำข้าม session (memory + skills)
  • ตั้งคิว Cron job อัตโนมัติ
  • มองเห็น แก้ไข จนเสร็จ ไม่มีการมองเห็น
