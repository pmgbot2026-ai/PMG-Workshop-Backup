📝 หลักการออกแบบ (Professional Design Principles)

  • 1. Peripheral Aisle (ทางเดินรอบอาคาร): ทางเดินรถกว้าง 4m วางด้านซ้ายของอาคาร ยาวตลอด 40m — รถวิ่งผ่านได้โดยไม่บล็อกช่องซ่อม
  • 2. Drive-In / Back-Out: แต่ละช่องเปิดประตูเข้าจากทางเดิน — รถเข้าหน้า ถอยออกหลัง ไม่ต้องเคลื่อนย้ายรถอื่น
  • 3. No Cross-Traffic: รถในช่องซ่อมไม่บล็อกทางเดิน — ทางเดินแยกอิสระจากช่องซ่อม
  • 4. Workflow บน → ล่าง: รับรถด้านบน → ประเมิน → ถอด → ซ่อมตัว → เตรียม → พ่นสี → ล้าง → ขัด → QC → ส่งด้านล่าง
  • 5. ทางเดินนอกอาคาร: รอบอาคารมีทางรถวิ่ง รถเข้า-ออกได้ทุกด้าน
  • 6. แยกโซน: บริการทั่วไป (ขวา) + เคลือบแก้ว (ซ้าย) แยกจากงานสี
  • 7. ตู้พ่นสี: ด้านหลังอาคาร ห่างฝุ่น — Comax/Nippon/PPG
  • 8. ชั้นลอย: ด้านหลัง 40×9m เก็บอะไหล่ + สำนักงาน
