📋 Job Description — ระบบ PMG War Room

🎯 วัตถุประสงค์

Dashboard แบบ Real-time สำหรับผู้บริหารและทีม PMG ติดตามผลงานขาย รายได้ กำไร และ KPI รายเดือน/รายปี เปรียบเทียบเป้าหมาย แสดงผลด้วยกราฟแท่ง เส้น และตาราง บนมือถือเป็นหลัก

🏗️ สถาปัตยกรรม — 4 ชั้น

  • Data Source: Google Spreadsheets 3 ไฟล์ — ไฟล์หลัก (D1_DTA1) + ไฟล์ประวัติ + ไฟล์เสริม
  • Backend: Google Apps Script (Code.gs) — อ่าน Sheets → แปลง → JSON → Cache
  • Frontend: HTML/JS (Index.html) — รับ JSON → Chart.js → 13 tabs
  • Delivery: GAS Web App — URL เดียว เข้าดูได้ทุกอุปกรณ์

📊 แท็บข้อมูล 13 หน้า

  • Dashboard — ภาพรวม KPI สำคัญ
  • OKR/KPI — เป้าหมาย vs ผลจริง
  • ปิดได้/ส่งมอบ — รถปิดได้ vs เป้า
  • การเงิน — รายได้ กำไร GM%
  • ประกันภัย — เบี้ยประกันแยกบริษัท
  • ช่องทาง — ยอดขายแยกช่องทาง
  • SA — ผลงาน SA รายบุคคล
  • เชียร์เคลม — เคลมรถเช่าซื้อ
  • YoY — เปรียบเทียบ 67/68/69
  • DTA — ข้อมูล DTA รายเดือน
  • ข้อมูลย้อนหลัง — สะสมหลายปี
  • ประเภทซ่อม — แยกประเภทงานซ่อม
  • ผลิตภัณฑ์เสริม — เบี้ยเสริม/SA/รายเดือน

⚙️ Tech Stack

  • Frontend: HTML5 + CSS3 + Vanilla JS — Mobile First
  • Charts: Chart.js 4.4.7 + DataLabels 2.2.0 (CDN)
  • Backend: Google Apps Script — SpreadsheetApp + HtmlService
  • Data: Google Sheets × 3 (private)
  • Deploy: clasp CLI → push → deploy

🔀 Flowchart — ขั้นตอนการทำงาน

Frontend (Index.html)

  • • Single-page HTML — ไม่มี framework
  • • Chart.js 4.4.7 + datalabels plugin
  • • 13 tabs, responsive, มือถือ First
  • • google.script.run → 13 async calls
  • • dlCfg() ตั้งค่า datalabels สีฟ้าสด
  • • mkC() สร้าง chart + auto-inject padding

Backend (Code.gs)

  • • doGet() → createHtmlOutputFromFile
  • • 13 data functions → JSON objects
  • • CacheService 5 min TTL
  • • Debug endpoints (?debug, ?api)
  • • SpreadsheetApp.openById() × 3
  • • ไม่มี HtmlTemplate (Caja issue)

Data Sources (3 Sheets)

  • • ไฟล์หลัก: OKR/การเงิน/ช่องทาง/SA
  • • ไฟล์ประวัติ: YoY/ข้อมูลย้อนหลัง
  • • ไฟล์เสริม: ประกันภัย/เคลม/ผลิตภัณฑ์
  • • Private → ต้องผ่าน GAS เท่านั้น
