Module Design / การออกแบบโมดูล ### 2.1 Global Variables (A-script.js) ```javascript var spreadsheet_id = ""; // Active spreadsheet target var form_name = ""; // Active form name var questions = []; // Loaded form questions array var questionImportance = {}; // Required field flags map var secret = "59c6ccf4..."; // Internal auth key (256-bit hex) var keyit = ""; // IT work order key ``` **Design Note:** These are script-level globals re-initialized on every invocation. Data Flow Diagram / แผนภาพการไหลของข้อมูล ### 3.1 Form Request Flow ``` Browser |── GET ?spreadsheet_id=X&form_name=Y | ▼ doGet(e) |── addParameter() × 3 → set globals |── spreadsheet_id check → route to error/main template | ▼ html-Index-vbs5 Template (rendered) |── getForms() → loads questions[] from A2_Forms |── include('Stylesheet') → CSS |── include('Rafco_JavaScript') → client JS | ▼ Browser renders form to user ``` ### 3.2 Form Submission Flow ``` User submits form | ▼ Client JS (google.script.run) |── uploadFileToDrive() for each file field |── getTimestamp() → timestampData |── insertBCT(formResponse, formData) → save to sheets/DB | ▼ insertBCT routing: reportR → BCT.loadUrlCenter → target sheet (AAM) reportR_RPLC → resolve branch → upsert sheet (RPLC) reportO_RAFCO_* → update B4_Audit sheet + SQL UPDATE default → BCT.autoInsert / autoInsertToSpreadsheetByFirebase ``` --- ## 4.
