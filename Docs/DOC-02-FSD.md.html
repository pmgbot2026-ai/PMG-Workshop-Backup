Functional Flows / ขั้นตอนการทำงาน ### 2.1 FSD-FR-CORE-001: Web App Request Processing **Trigger:** HTTP GET request to web app URL **Actor:** End user via web browser **Flow:** ``` User → GET /?spreadsheet_id=X&form_name=Y&keyit=Z doGet(e) ├── Check AGSCheckStatusService param │ YES → return JSON {"status":"ok"} ├── addParameter(spreadsheet_id) → set global var ├── addParameter(form_name) → set global var ├── addParameter(keyit) → set global var ├── Check spreadsheet_id == PMG error ID? │ YES → createTemplateFromFile('PMG-Error') → return ├── Check spreadsheet_id == PKG error ID? │ YES → createTemplateFromFile('PKG-Error') → return └── createTemplateFromFile('html-Index-vbs5') .evaluate() → IFRAME sandbox, ALLOWALL XFrame → return ``` **Business Rule BR-CORE-001:** spreadsheet_id `1uH3LeYt7LS0l8Lg3wHqv2mSBg-9HT85ClK4-J49roCA` maps to PMG-Error page. **Business Rule BR-CORE-002:** spreadsheet_id `1-puCL6LQUoVPnlvVI73yCeKLQwLD0zXS8VagBKJMKmE` maps to PKG-Error page. --- ### 2.2 FSD-FR-CORE-002: Form Definition Loading **Trigger:** Client-side HTML template initialization calls `getForms()` **Actor:** HTML template (server-side) **Flow:** ``` getForms() ├── Check spreadsheet_id != "" (global var must be set) ├── SpreadsheetApp.openById(spreadsheet_id) ├── getSheetByName('A2_Forms') ├── BCT.form_getRowByKey(sheet, 'process') → rowByKey ├── BCT.getFields(sheet, rowByKey+1, 1, 0) → fields array ├── BCT.getValuesAll(sheet, rowByKey+5, 1) → all form rows ├── For each row: │ If valueByFliedName(fields, values, 'form_name') == form_name (global) │ → push to questions[] global array │ → if form_importance == 'บังคับกรอก' → add to questionImportance{} │ → if forms == {} → set forms = this row JSON └── return forms (first matching row as JSON) ``` **Output:** `forms` object (first question metadata), `questions[]` array (all questions), `questionImportance{}` (required field flags) --- ### 2.3 FSD-FR-UPLOAD-001: File Upload to Google Drive **Trigger:** Form submission containing Base64-encoded file data **Actor:** Form submission handler (client → server) **Pre-condition:** Base64 data, target folder ID, file name, and field name must be provided. **Flow:** ``` uploadFileToDrive(base64Data, fileName, folders, fieldname) ├── fileName += "_" + formatDate(now, 'GMT+7', 'yyyyMMddhhmmsss') ├── Parse MIME type from base64Data header ├── Utilities.base64Decode(base64 content) ├── Utilities.newBlob(bytes, mimeType).setName(fileName) ├── DriveApp.getFolderById(folders) ├── folder.createFile(blob) ├── file.setOwner("gdoc@prachakij.com") └── return { fieldname, fileUrl, base64Data, fileName, folders } On error → return 'Error: ' + e.toString() ``` **Folder Creation Sub-flow:** ``` newFileToNewFolder(fieldname, parentFolderId, filename, folderName) ├── DriveApp.getFolderById(parentFolderId) ├── Search for existing sub-folder by name │ EXISTS → use existing folder ID │ NOT EXISTS → createFolder(folderName).getId() └── return { form_question_fieldname, form_upload_folder: folderId, form_upload_filename } ``` --- ### 2.4 FSD-FR-INSERT-001: Form Response Routing and Insertion **Trigger:** Form submission with complete form data **Actor:** Form submission handler **Flow:** ``` insertBCT(formResponse, formData, formIndex) For each spreadsheet_id in formResponse: ├── Extract DLT fields (form_dlt_type, form_dlt_topic_id, form_dlt_data) │ If type == "HCS" → generate DLT token │ ├── ROUTING LOGIC: │ Case "reportR": │ BCT.getReportT_NameBrand(ctt_code) → branch │ BCT.loadUrlCenter('BCT_Report_R', 'cpy_code', branch, 'url_key') → spreadsheet_id │ → standard insert │ │ Case "reportR_RPLC": │ Resolve spreadsheet_id from branch │ Query BCT_RPLC for Primary Key │ → UPDATE if row exists, else INSERT via autoInsertToSpreadsheetByFirebase │ │ Case "reportO_RAFCO_saveUploadAudit": │ Look up report folder from center config sheet │ Update B4_Audit_นิติกรรม sheet in branch spreadsheet │ Also update BCT Audit sheet (1ar0svSfjHxMsTkcmEGZKJbJLWbUj1WPx5Gi-dmI5QO4) │ Execute SQL UPDATE on RAFCO_act table │ │ Default (direct spreadsheet_id): │ → standard BCT insert/update ``` --- ### 2.5 FSD-FR-RAFCO-001: Contract Search via Elasticsearch **Trigger:** Client calls `searchContract_Rafco(Keyword, nameUseID)` **Actor:** Client-side form (via google.script.run) **Flow:** ``` searchContract_Rafco(Keyword, nameUseID) ├── Build Elasticsearch bool/should query: │ Fields: ctt_code, cust_name, id_card, addr_tel │ Wildcard: "*" + Keyword + "*" ├── BCT.loadJSONQuery_Elasticsearch('tbcontract_data', 'tbcontract_data', payload) ├── BCT.loadJSONDatas('', '', '', cached, '') → datas └── return { "nameUse-ID": nameUseID, datas: datas } ``` --- ### 2.6 FSD-FR-RAFCO-002: RAFCO Memo Retrieval **Flow:** ``` getmemo_rafco(Keyword) ├── SQL: "select * from tbmemo where memo_ctt_code like 'Keyword' order by update_time desc limit 1" ├── BCT.loadJSONDatas(BCT.getDBServer(), 'BCT_AMS2_RAFCO', query) └── return datas[0] (most recent memo) ``` --- ### 2.7 FSD-FR-FAM-001: FAM Rent Contract Lookup **Flow:** ``` loadDropdownIdRent(name) ├── Open spreadsheet 1vHgII04pPtYFO_6PzoqVmm1FXM9kLNlNAWv_fkrRNhk ├── Sheet: B2_Contract ├── Filter: name_rent == name AND status_contract != "ยกเลิก" └── return array of { id_rent } objects loadRent(id_rent) ├── Same spreadsheet/sheet ├── Find row where id_rent matches └── return { tenancy, rentalrate, rent, tokenRentLine } loadIIU(gen_key) ├── Open spreadsheet 1v7sh2JqwZEGVV6ZXNVTTBQq7dGVW7W_jLgmBpt0Om1c ├── Sheet: IIU_FIM_Step_1 ├── Find row where gen_key matches Search (MIRAI Database) **Flow:** ``` getpart_norMultiKey(Keyword, nameUseID) ├── DB: MIRAI ├── Table: NonMovementPartsReport_th (join pic as pic_c) ├── WHERE Column3 LIKE '%Keyword%' OR Column4 LIKE
