Overview / ภาพรวม BCT-196 does not own or manage a dedicated database. Instead, it reads from and writes to: 1. **Google Spreadsheets** (used as structured data stores / configuration sheets) 2. **External SQL Databases** (accessed via BCT library BCT.loadJSONDatas / BCT.loadXMLDatas) 3. **Elasticsearch** (RAFCO contract search via BCT.loadJSONQuery_Elasticsearch) 4. **Google Drive** (file storage) BCT-196 ไม่มีฐานข้อมูลเฉพาะ แต่อ่าน/เขียนข้อมูลจาก Google Spreadsheets, SQL databases ภายนอก, Elasticsearch และ Google Drive --- ## 2.
